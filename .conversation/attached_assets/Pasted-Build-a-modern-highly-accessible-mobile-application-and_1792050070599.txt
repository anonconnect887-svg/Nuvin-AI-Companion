Build a modern, highly accessible mobile application (andriod and IOS) for "Nuvin" (A trusted, consent-first AI Companion & Everyday Assistant). 

### 1. Product Overview & Ethos
Nuvin is an empathetic, voice-first AI companion serving two distinct personas:
1. Elder Persona (55+): Respectful tone ("Aap/Ji"), extra-large typography, high contrast, clutter-free tabless screen, focus on health, medication reminders, and safety.
2. Ear Persona (20–50): Warm, peer-like tone ("Tum/Friend"), modern sleek aesthetic, focus on daily decompression, emotional venting, habit tracking, and memory journaling.

### 2. Design System & Aesthetics
- Visual Theme: Calming, soothing, trust-inducing dark/deep slate theme with vibrant accents.
  - Background: Deep Navy Slate (`#0B132B` / `#1C2541`)
  - Accent / Glow: Cyan Neon (`#00F0FF` / `#48CAE4`) and Warm Amber (`#FFB703`)
  - Danger / SOS: High-visibility Red (`#E63946`)
  - Surface Cards: Translucent frosted glass with subtle borders (`rgba(255, 255, 255, 0.08)`, backdrop-blur-md).
- Typography: Clean sans-serif (Inter or Plus Jakarta Sans). Include a Persona Toggle at the top:
  - When "Elder Mode" is toggled ON: Scale base typography to 20px–24px, increase button hit targets to min 56px, and simplify text descriptions.
  - When "Ear Mode" is active: Sleek 16px body, compact modern layout.
- Responsive: Mobile-first viewport (iPhone/Android frame centered on desktop, fully responsive on mobile devices).

### 3. Screen Structure & Layout (Tabless, Single-Window Architecture)

#### A. Header Bar (Sticky Top)
- Left: App Logo with glowing dot indicator ("Nuvin • Online").
- Center: Quick Persona Switcher pill ("🧓 Elder Mode (55+)" / "🎧 Ear Mode (20-50)").
- Right:
  - Memory Vault Icon button (opens slide-over drawer).
  - Emergency SOS Button (Bright Red pill `[ 🚨 SOS ]` that triggers a confirmation modal with 5-second countdown siren and live location tracker preview).

#### B. Central Voice Orb Component (Hero Element)
Create an animated, pulsating, organic glowing 3D-effect Voice Orb in the center:
- 4 Interactive States (clickable to cycle for demonstration):
  1. Idle: Soft, slow breathing pulse with cyan glow.
  2. Listening: Dynamic waveform ripples reacting to simulated microphone input.
  3. Thinking: Orbiting glowing amber particles revolving around the core.
  4. Speaking: Energetic soundwave ripples pulsing outward.
- Below the Orb, display a subtle live status indicator: "Tap Orb to speak, or say 'Hey Nuvin'".

#### C. Conversation Stream with OpenUI Micro-Action Cards
Underneath the Orb, provide a scrollable, streaming message history between User and Nuvin. Messages must support structured rich UI micro-cards:
1. Medication Reminder Card:
   - Header: 💊 "Afternoon Blood Pressure Medicine"
   - Body: "Amlodipine 5mg • 1 Tablet with warm water"
   - 4-Action Ladder Buttons:
     - `[ ✅ Taken ]` (Success badge)
     - `[ ⏱️ Snooze 15m ]`
     - `[ ⏭️ Skip ]`
     - `[ 🆘 Need Help ]` (Alerts caregiver)
2. Memory Vault Card:
   - Header: 🧠 "Memory Saved"
   - Body: "Nuvin noted: 'Grandson Aarav's birthday is coming up on October 24th.'"
   - Action: `[ 🗑️ Forget This ]` button (Consent-first principle allowing instant memory deletion).
3. Crisis / Helpline Card (Triggered on emotional distress):
   - Header: 🛡️ "We Are Here With You"
   - Direct Call Pills: `[ 📞 Tele-MANAS: 14416 ]` and `[ 📞 KIRAN: 1800-599-0019 ]`.

#### D. Bottom Interaction & Audio Bar (Sticky Bottom)
- Audio Output Mode Selector:
  - `[ 🔊 Speaker ]` (Loud hands-free audio)
  - `[ 📞 Call Mode ]` (Earpiece mode for private venting)
- Input Tray:
  - Text input field ("Type a thought or question...")
  - Microphone button (Holds to talk / tap to toggle Voice Orb)
  - Send button

### 4. Interactive Drawers & Modals to Include

1. Onboarding Modal ("Welcome to Nuvin"):
   - Step 1: Choose Persona (Elder 55+ vs Ear 20-50).
   - Step 2: Name your Companion ("Hey Nuvin", "Hey Saathi", etc.).
   - Step 3: Add Emergency Kin Contact (Name + Phone number).
   - Step 4: Voice Enrollment simulated visualizer (3 samples).

2. Memory Vault Drawer (Slide-over from right):
   - Shows all active vector memories categorized by:
     - "Health & Medication"
     - "Family & Relationships"
     - "Daily Preferences & Habits"
   - Each memory has a timestamp, an explanation of why Nuvin remembered it, and a "Delete / Forget" button with zero friction.

3. SOS Emergency Overlay:
   - Full-screen flashing soft amber/red overlay.
   - 5-second cancel countdown timer.
   - Shows simulated SMS dispatched to Primary Kin with 8-Hour Google Maps live tracking preview and siren volume toggle.

### 5. Technical & Polish Details
- Use Tailwind CSS, Framer Motion for smooth Orb animations and card entry transitions, and Lucide Icons.
- Pre-populate realistic bilingual mock data (English and Hinglish conversational examples like "Aapka BP medicine lene ka samay ho gaya hai").
- Ensure all interactive buttons have hover states, tap feedback, and accessibility aria-labels.
